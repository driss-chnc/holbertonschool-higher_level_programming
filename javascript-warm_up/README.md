# JavaScript - Warm up

Ce dossier regroupe les premiers exercices du projet **JavaScript - Warm up** de Holberton School. Ils permettent de découvrir JavaScript et de prendre en main Node.js à travers de petits programmes exécutés depuis le terminal.

## Exercice

| Fichier | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Affiche `JavaScript is amazing` dans le terminal. |

## Prérequis

- Node.js installé sur votre machine.

## Exécuter le programme

Depuis ce dossier, lancez :

```bash
./0-javascript_is_amazing.js
```

Vous pouvez aussi l'exécuter directement avec Node.js :

```bash
node 0-javascript_is_amazing.js
```

Le résultat attendu est :

```text
JavaScript is amazing
```

## À propos de JavaScript

JavaScript est un langage de programmation polyvalent, utilisé notamment pour rendre les pages web interactives et pour développer des applications côté serveur avec Node.js. Dans ce projet, les scripts sont exécutés avec Node.js, sans navigateur.
